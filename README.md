# Горький Навигатор — веб-прототип

Интерактивная демонстрация трёх связанных сценариев:

1. навигация от КПП до нужной двери;
2. выбор павильона и дат;
3. подготовка обязательного пакета к съёмке и контроль сроков.

## Опубликованная версия

После создания репозитория GitHub Actions автоматически публикует `main` в GitHub Pages.

## Локальный запуск

Из папки `prototype` запустите любой локальный статический сервер, например:

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

Прототип не отправляет данные во внешние системы. Статусы документов и черновик бронирования сохраняются только в `localStorage` браузера. Даты, участники и статусы являются демонстрационными. Геометрия комплекса не выдумывается: вместо неё показан сценарий пути, а реальный план появится только после получения утверждённой схемы Киностудии Горького.

Фотографии взяты из [официальной публикации Киностудии Горького](https://gorkyfilm.ru/calendar/otkrylis-novye-semochnye-pavilony-na-ploshhadke-kinostudii-gorkogo-v-valdajskom-proezde/) и используются только в этом демонстрационном прототипе.
